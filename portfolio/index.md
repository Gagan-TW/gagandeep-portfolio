## How I work

The same habits run through both projects.

- **I test everything.** Every request in the docs runs against a mock server before it is published.
- **I write for three readers.** End users, developers, and partner integrators each get the pages they need.
- **I let tools check the basics.** Vale checks style and Redocly checks the API spec on every change, so reviews can focus on meaning.
- **I treat AI as a first draft.** Prompts are versioned and tested. A human checks every generated page against the source.

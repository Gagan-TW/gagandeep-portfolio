# Gagandeep Kaur | Portfolio & Learning Space

A polished personal website and knowledge hub built with [Docusaurus](https://docusaurus.io/) to showcase work at the intersection of technical writing, developer workflows, and software documentation.

This project reflects a clear professional story: I build documentation that is useful to engineers, I learn the tools developers use, and I turn complex ideas into content that is easy to understand, useful, and actionable.

It is designed for:

- Recruiters evaluating communication, technical depth, and product thinking
- Technical writers exploring docs-as-code, API documentation, and developer tooling
- Engineers who value clear documentation and collaborative workflows
- Anyone who wants to see how writing and code can work together

## Why this project exists

In modern product teams, the strongest contributors are not only technical experts; they are also clear communicators. This portfolio demonstrates that ability by combining:

- Developer-focused writing
- Git and GitHub workflow literacy
- REST API understanding
- Python and SQL fundamentals
- Docs-as-code principles
- A public, accessible, well-structured learning presence

The site acts as both a portfolio and a learning archive — a place where ideas, study notes, and engineering knowledge are organized in a way that is useful to both humans and teams.

## Getting started

### Prerequisites

- Node.js 18+
- npm or yarn

### Install dependencies

```bash
npm install
```

### Run locally

```bash
npm start
```

This starts the development server and opens the site in the browser. Most changes are reflected live while editing.

### Create a production build

```bash
npm run build
```

This generates a static build in the `build/` folder.

### Serve the production build locally

```bash
npm run serve
```

## Deployment

This site is configured for GitHub Pages-style deployment workflows.

Using SSH:

```bash
USE_SSH=true npm run deploy
```

Without SSH:

```bash
GIT_USER=<your-github-username> npm run deploy
```

# SQL for Non-Developers

Many products sit on a database. When you can run a simple query, you can check facts yourself instead of waiting for someone else.

**Who this is for:** Writers who document data, reports, or admin features.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. Tables, rows, and columns
2. SELECT and WHERE
3. Sorting and filtering
4. Joining two tables
5. Reading a data model
6. Documenting a database clearly

New lessons appear in the sidebar as they are published. Each one links to its matching video.

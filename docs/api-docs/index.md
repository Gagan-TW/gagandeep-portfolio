# API Documentation Guide

Developers judge a product by its API docs. This track walks through the full API doc set, from the first quickstart to the error reference, using one example API throughout.

**Who this is for:** Writers who are new to API docs, and writers who want their API docs to feel like Stripe or Twilio.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. What a complete API doc set contains
2. Reading an OpenAPI spec
3. Writing a 5-minute quickstart
4. Documenting authentication
5. Writing an endpoint reference page
6. Errors that tell the reader how to fix them
7. Documenting webhooks and events

New lessons appear in the sidebar as they are published. Each one links to its matching video.

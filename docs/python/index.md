# Python for Technical Writers

Python is the language behind most automation and AI tools. Writers do not need to become developers. Knowing enough Python to read a script and automate a boring task is a real advantage.

**Who this is for:** Writers who want to read code samples confidently and automate small tasks.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. Why Python, and how to set it up
2. Variables, lists, and dictionaries
3. Loops and conditions
4. Reading and writing files
5. Working with JSON and YAML
6. Calling an API from Python
7. How AI models learn from data

New lessons appear in the sidebar as they are published. Each one links to its matching video.

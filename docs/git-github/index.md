# Git & GitHub for Writers

You do not need every Git command. You need about ten, and you need to know when to use them. This track teaches exactly those.

**Who this is for:** Writers who have been asked to "just open a PR" and felt lost.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. What Git is and why teams use it
2. Clone, commit, and push
3. Branches for every change
4. Pull requests and reviews
5. Fixing a merge conflict calmly
6. Reading a repo you did not write

New lessons appear in the sidebar as they are published. Each one links to its matching video.

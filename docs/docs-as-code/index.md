# Docs-as-Code Workflow

Docs-as-code means your docs live in Git, are written in Markdown, and are checked and published automatically. It sounds technical. It is mostly a habit.

**Who this is for:** Writers moving from Word, Confluence, or a help authoring tool to Markdown and Git.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. What docs-as-code really means
2. Markdown you will use every day
3. YAML front matter and config files
4. Building a site with Docusaurus
5. Checking style automatically with Vale
6. Quality checks in GitHub Actions

New lessons appear in the sidebar as they are published. Each one links to its matching video.

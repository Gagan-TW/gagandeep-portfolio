# REST APIs Explained Simply

Once you can call an API yourself, you stop guessing how it behaves. This track takes you from your first request to reading real responses with confidence.

**Who this is for:** Writers who document APIs but have never called one.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. What an API is, in plain words
2. Requests, responses, and status codes
3. Your first call in Postman
4. Headers, keys, and tokens
5. Reading JSON without fear
6. Testing what the docs say

New lessons appear in the sidebar as they are published. Each one links to its matching video.

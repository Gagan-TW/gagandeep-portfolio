# Writing Rules That Always Work

Good docs are not about fancy words. They are about a reader finishing a task without getting stuck. This track covers the rules I use on every page I write.

**Who this is for:** Writers who want a simple, repeatable way to make every page clearer.

## What you will learn

Lessons are added here one at a time. This is the order I plan to teach them.

1. Write for one reader at a time
2. Short sentences and active voice
3. Headings that help people scan
4. Procedures: one action per step
5. Consistent terms and why they matter
6. Using a style guide without memorizing it

New lessons appear in the sidebar as they are published. Each one links to its matching video.
